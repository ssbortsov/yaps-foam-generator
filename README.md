# YAPS — генератор пены

Векторный паттерн пены: ячейки строятся по взвешенной диаграмме Вороного (диаграмме Лагерра), вжимаются внутрь на половину зазора, скругляются по углам и выгибаются по граням. Сетка — это то, что осталось между ячейками. Экспорт в SVG.

Открыть: [ssbortsov.github.io/yaps-foam-generator](https://ssbortsov.github.io/yaps-foam-generator/)

## Зачем

Обычная диаграмма Вороного даёт прямые рёбра и читается как трещина или кристалл. Пена устроена иначе: пузыри разного размера, давление внутри обратно пропорционально радиусу, поэтому границы смещены к мелким, а плёнки выгнуты дугой. Генератор воспроизводит эту логику и даёт ей настройки.

## Как работает

1. Точки раскидываются случайно с запасом за кадром, чтобы паттерн не обрывался по краю.
2. Три итерации Ллойда выравнивают раскладку.
3. Заданное число точек получает большой вес, их ближайшие соседи — нулевой. Так крупный пузырь вытесняет мелких, а не просто занимает больше места.
4. Ещё две итерации Ллойда с весами.
5. Каждая ячейка вжимается внутрь на половину зазора плюс запас под будущий прогиб, углы срезаются на радиус и заменяются кривой через исходную вершину, грани выгибаются наружу.
6. Всё собирается в один `path` с правилом `evenodd`: холст закрашен, ячейки вычтены дырками.

Наложение соседних ячеек исключено конструктивно: запас под прогиб вычитается заранее, поэтому выгнутая грань возвращается ровно на половину зазора и дальше не идёт.

## Параметры

| Параметр | Что делает |
|---|---|
| Плотность | Число ячеек в кадре |
| Крупных пузырей | Сколько точек получают большой вес |
| Мелких на крупный | Сколько ближайших соседей каждого крупного обнуляются |
| Контраст размеров | Насколько крупные отличаются от средних |
| Скругление углов | Радиус как доля от короткой из смежных граней |
| Выпуклость граней | Прогиб грани наружу как доля от её длины |
| Зазор в узком месте | Ширина перемычки на середине грани; в узлах она всегда шире |
| Перепад зазора сверху вниз | Зазор уже вверху кадра, шире внизу |
| Сид | Фиксирует раскладку: одни и те же параметры с одним сидом дают один и тот же паттерн |

Кнопка «Скопировать настройки» выдаёт строку со всеми значениями. Она же пишется в `<desc>` экспортированного файла — без неё паттерн невоспроизводим.

## Экспорт

SVG выходит в кривых, одним `path`, без обводок. Ячейки можно оставить прозрачными — тогда под паттерн подставляется любой фон.

## Локально

Зависимостей нет. Достаточно открыть `index.html` в браузере.
